Part I

Platform Vision, Philosophy & Scope

High-level platform objective, scope restrictions, and primary ecosystem roles.

01 Platform Overview & Core Concept #

PoOS (Project & Open-source Opportunity System) is a contribution-driven technical project collaboration and talent discovery platform designed to connect students, colleges, mentors/professionals, IT companies, and non-IT companies through real technical projects and demonstrated capabilities.

PoOS is NOT a traditional job portal.

The platform allows students and technical professionals to build their technical identity through:

  • Real projects
  • Technical contributions
  • Technical skills
  • Technologies
  • Experience
  • GitHub activity
  • Achievements
  • Certificates
  • Project leadership

Companies from both IT and non-IT industries can discover suitable technical professionals based on this evidence and directly connect with them for technical opportunities.

02 Core Platform Philosophy #

The core philosophy of PoOS is:

"Don't ask students to apply for opportunities. Let their work create the opportunity."

The core concept is:

Build → Contribute → Prove → Get Discovered

Instead of the traditional recruitment pipeline:

Traditional Model (NOT PoOS)
Resume → Job Application → Screening → Recruitment Pipeline
PoOS Ecosystem Flow
CREATE PROJECT → JOIN PROJECT → BUILD & CONTRIBUTE → DEMONSTRATE SKILLS → BUILD REPUTATION → SUPER PROFILE → COMPANY DISCOVERS TALENT → COMPANY CONTACTS PERSON → REAL-WORLD OPPORTUNITY

03 Platform Objective & Scope #

The primary objective of PoOS is to create a technical ecosystem where a person's actual technical work becomes a major part of their professional identity.

The platform helps each ecosystem member:

  • Students: Build technical experience and demonstrate their capabilities.
  • Colleges: Manage students, departments, projects, participation and technical activities.
  • Mentors: Guide students, review contributions, and contribute technical expertise.
  • IT Companies: Discover technical professionals for their software and engineering requirements.
  • Non-IT Companies: Discover technical and business contributors for their internal technical and industry project requirements.
Technical Roles Covered

PoOS supports technical roles such as:

Software Developer Frontend Developer Backend Developer Full Stack Developer Web Developer Mobile Developer Python Developer Java Developer JavaScript Developer TypeScript Developer AI Engineer Machine Learning Engineer AI/ML Engineer Data Scientist Data Analyst Data Engineer Cloud Engineer DevOps Engineer Cybersecurity Engineer Database Developer Blockchain Developer Technical Researcher Open Source Contributor

The technical role and skill system is extensible so administrators can add new technical roles in the future.

04 Important Scope Restrictions #

The following scope rules are mandatory:

No Faculty Role

PoOS will have College Admin as the college-level administrator. Do NOT create a Faculty role or Faculty dashboard.

No General Job Portal

PoOS will not function as a conventional job portal. Do NOT implement Job Postings, Job Listings, Apply Now, Job Applications, or Resume Applications.

No Innovation & Incubation Module

Remove Innovation & Incubation completely from the Student and College Portal scope.

Testing / QA Scope

Testing / QA is NOT a platform scope or talent category. Do not create a Testing role, QA role, Testing dashboard, or QA talent category module.

Part VI

Technical Architecture & System Design

Database schema, technology stack, backend APIs, OpenSearch, Redis, Celery, and AI integration.

41 Database Architecture (PostgreSQL) #

Core Database Entities: - users, roles - student_profiles, college_profiles, college_admins, departments - mentor_profiles, professional_profiles - company_profiles, company_types, company_industries - projects, project_members, project_roles, project_tasks, project_issues, project_discussions, project_documents, project_releases, project_activity - contributions, commits, pull_requests, reviews - skills, user_skills, project_skills - achievements, badges, certificates - events, event_participants - mentorship_sessions, mentor_relationships - leaderboards, shortlists, contact_requests, notifications, audit_logs

42 Company Types Schema #

Company profile schema includes company_type (IT, NON_IT), industry, company_size, location, website, description, skills_needed, and projects.

43 Role-Based Access Control (RBAC) #

Strict RBAC for Student, College Admin, Mentor, IT Company, and Non-IT Company. Users only access endpoints and data authorized for their role.

44 Dashboard UI Differentiation #

IT Dashboard highlights technical talent, software projects, AI/ML, Cloud, DevOps, and code contributions. Non-IT Dashboard highlights business talent, industry projects, data analytics, finance, marketing, and operations.

45 Recommended Technology Stack #

Frontend

  • Next.js 14+ (TypeScript)
  • Tailwind CSS
  • shadcn/ui & Lucide React
  • TanStack Query & Zustand
  • React Hook Form & Zod

Backend

  • Python 3.11+
  • FastAPI Framework
  • Pydantic Validation
  • SQLAlchemy ORM
  • Alembic Migrations

Database & Search

  • PostgreSQL (Primary DB)
  • OpenSearch (Talent Search)
  • pgvector (Vector Embeddings)
  • Redis (Cache & Queues)

46 OpenSearch Integration #

OpenSearch indexes for Technical Profiles, Projects, Skills, Technologies, Contributions, and Mentors to provide instant multi-faceted search query execution.

47 Redis & Celery Stack #

Redis for caching and rate-limiting. Celery workers for background tasks: GitHub synchronization, contribution processing, leaderboard calculation, search indexing, AI profile generation, and certificate rendering.

48 GitHub Sync Data Pipeline #

GitHub Webhook / API → Celery Background Worker → Contribution Engine → PostgreSQL → OpenSearch Index → Super Profile Update

49 AI / ML Stack & Vector Search #

OpenAI API for LLM features and OpenAI Embeddings with pgvector in PostgreSQL for vector search matching across profiles, projects, mentors, and company requirements.

50 Storage & WebSockets #

Supabase Storage / S3 for profile images, project documents, and certificates. FastAPI WebSockets for real-time notifications, project activities, and contact request updates.

51 Authentication & Security #

Email/Password, Google OAuth, GitHub OAuth, JWT access/refresh tokens, input sanitization, rate limiting, CORS controls, and comprehensive audit logs.

52 Intelligent Recommendation Engine #

Algorithms for Student → Project matching, Student → Mentor matching, IT Company → Talent matching, and Non-IT Company → Talent matching based on skills, domain, industry, and project experience.

53 AI Features Architecture & Rules #

AI features include AI Project Matching, Talent Discovery, Skill Analysis, Profile Summaries, Project Assistant, and Industry Matching. CRITICAL RULE: AI must NEVER invent projects, skills, contributions, experience, certificates, employment history, or GitHub activity.

54 Performance Optimization #

Database indexing, pagination, lazy loading, Redis caching, search indexing, and background task execution ensure fast response times.
